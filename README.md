# NEKON Toolkit

Public developer tools for building private communication experiences on NEKON.

This repository is being initialized. The first implementation extracts framework-independent design tokens and adds local package verification. SDK/runtime extraction, UI components and developer tooling are tracked in [the roadmap](https://github.com/powerpuff-kitty/nekon-toolkit/issues/1).

**Status:** source preview; no packages published, no production-readiness claim. The hosted platform and first-party applications remain in the separate `nekon` repository.

Target board: [Project 14](https://github.com/users/powerpuff-kitty/projects/14). Repository issues exist; board synchronization is not yet verified.
